# 主题中心容错与边界处理

**文档状态：** 已落地（H5 / 微信小程序统一逻辑）  
**对应实现：** `frontend/src/services/themeFault.js`、`frontend/src/services/themeCenter.js`

乡声集盒主题中心在浏览器 H5 与微信小程序使用同一套容错：页面不崩溃、不白屏；云端同步失败时降级本地存储；异常按 **用户操作 / 网络 / 服务端数据 / 环境限制** 分类，并给出对应友好提示。

装扮目录默认使用内置清单。可通过 `setThemeCatalogFetcher` / `setThemeCloudFlusher` / `setThemeMemberFetcher` 注入远端接口；未注入时不会对不存在的目录接口发起请求。总览见 [`THEME_CENTER.md`](THEME_CENTER.md)。字段与接口见 [`THEME_CENTER_DATA.md`](THEME_CENTER_DATA.md)。分期与小程序降级见 [`THEME_CENTER_ROADMAP.md`](THEME_CENTER_ROADMAP.md)。跳转链路见 [`THEME_CENTER_NAV.md`](THEME_CENTER_NAV.md)。运营后台见 [`THEME_CENTER_ADMIN.md`](THEME_CENTER_ADMIN.md)。列表卡顿、样式注入与缓存见 [`THEME_CENTER_PERF.md`](THEME_CENTER_PERF.md)。越权启用与非法 id 见 [`THEME_CENTER_SECURITY.md`](THEME_CENTER_SECURITY.md)。

## 异常分类

| 种类 | `THEME_FAULT_KIND` | 提示原则 |
| --- | --- | --- |
| 用户操作 | `user` | 防抖、存储上限、登录合并选择 |
| 网络 | `network` | 检查网络、重试；可展示缓存 |
| 服务端数据 | `data` | 资源异常、回退默认样式 |
| 环境限制 | `env` | 明确是小程序/版本限制，不是程序错误 |

Toast 文案见 `THEME_FAULT_TOAST`，长度不超过 32 字。

## 一、网络异常

1. **加载主题/装扮列表失败**  
   无缓存：空态「装扮列表加载失败，请检查网络后重试」+【重试】。  
   有缓存：继续展示列表，并提示「当前展示为缓存数据，部分内容可能不是最新」。

2. **保存装扮、同步云端失败**  
   先写入 H5 `localStorage` / 小程序 storage，当前页立即生效。  
   Toast：「装扮已本地生效，云端同步失败，稍后会自动重试」。  
   登录态下排队 `ui_theme_pack_cloud`，网络恢复（`onNetworkStatusChange`）后自动 flush。

3. **收藏、保存搭配失败**  
   本地已标记成功。Toast：「操作已本地保存，同步云端失败，网络恢复后自动同步」。

未登录只写本地，不同步云端。

## 二、服务端数据异常

1. **装扮 id 不存在或已删除**  
   卡片置灰，标注「装扮已下架」；历史记录预览/启用置灰。一键应用跳过该装扮，Toast：「部分装扮已下架，已自动跳过」。

2. **缺少预览图或样式 JSON**  
   使用默认占位；提示「装扮资源加载异常」；启用按钮置灰。

3. **样式 JSON 损坏**  
   不渲染异常样式，回退系统默认。Toast：「装扮样式加载异常，已恢复默认」。

## 三、权限与状态边界

1. **会员状态跨端未同步**  
   「会员状态正在同步，请稍候」，拉取完成后再渲染权限。

2. **已拥有但小程序不支持该组件**  
   权限仍显示已拥有；标注「拥有权限，但小程序环境暂不支持该装扮」；启用置灰。

3. **活动装扮已绝版**  
   卡片【已绝版】，无法再次启用；历史搭配一键应用自动跳过。

4. **开启「全局主题覆盖局部装扮」且已有局部装扮**  
   弹窗：「开启全局主题覆盖局部装扮后，自定义局部装扮将不会生效，是否继续？」确认/取消。

## 四、存储边界

1. **历史搭配满 10 套**  
   弹窗：「已达到最大保存数量，请删除旧搭配方案后再保存」。

2. **本地存储空间不足**  
   Toast：「存储空间不足，无法保存装扮配置，请清理存储空间」。当前会话仍可临时生效，不持久化。

## 五、登录状态

1. **未登录**  
   只保存在本地。底部：「未登录状态，装扮仅保存在本地，登录后可同步到云端」。

2. **从未登录 → 登录**  
   云端配置优先。若本地有未同步装扮，询问：使用云端配置 / 使用本地配置 / 合并两者。

3. **账号 A 登出后登录 B**  
   清空旧账号本地装扮记录，加载新账号云端配置（由 `handleThemeAccountLogin` 在登录后执行）。

## 六、小程序特有

1. **基础库过低**（低于 `2.10.0`）  
   弹窗：「当前小程序版本过低，请更新小程序后使用装扮功能」；相关按钮置灰。

2. **保存分享海报被拒**  
   Toast：「保存海报失败，请授予相册权限」。

## 七、UI 交互

1. **连续点击启用/应用**  
   800ms 防抖，只执行一次。

2. **预览关闭时仍在渲染**  
   `abortThemePreview` 提升预览世代，终止预览渲染，不写入真实界面样式。

## 八、提示规范

- 网络：检查网络、重试  
- 数据：资源异常、回退默认  
- 环境：小程序限制，不是 bug  
- 权限：开通会员 / 参与活动  
- 存储：清理空间  

所有异常不得导致页面崩溃或白屏。
