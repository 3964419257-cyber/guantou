# 主题中心容错与边界处理

**文档状态：** 一期 MVP（独立拆分；异常分类、拦截与已落地提示以本文为准）  
**产品：** 乡声集盒 · 主题中心 · 全场景异常与边界兜底  
**对应实现：** `frontend/src/services/themeFault.js`、`frontend/src/services/themeCenter.js`、`frontend/src/services/themeApi.js`

本文只定 **异常怎么分类、怎么拦截、怎么自愈、提示哪一句**。空态 / 占位 UI 见 [`THEME_CENTER_STATUS.md`](THEME_CENTER_STATUS.md)。本地与云端队列见 [`THEME_CENTER_SYNC.md`](THEME_CENTER_SYNC.md)。启用校验见 [`THEME_CENTER_SECURITY.md`](THEME_CENTER_SECURITY.md)。权限过期见 [`THEME_CENTER_PRIVILEGE.md`](THEME_CENTER_PRIVILEGE.md)。搭配跳过失效件见 [`THEME_CENTER_MIX.md`](THEME_CENTER_MIX.md)。预览沙盒见 [`THEME_CENTER_PREVIEW.md`](THEME_CENTER_PREVIEW.md)。性能与 `theme_perf_error` 见 [`THEME_CENTER_PERF.md`](THEME_CENTER_PERF.md)。埋点见 [`THEME_CENTER_ANALYTICS.md`](THEME_CENTER_ANALYTICS.md)。分期见 [`THEME_CENTER_ROADMAP.md`](THEME_CENTER_ROADMAP.md)。标准化数据结构（独立拆分）见 [`THEME_CENTER_DATA.md`](THEME_CENTER_DATA.md)。

乡声集盒主题中心在浏览器 H5 与微信小程序使用同一套容错：页面不崩溃、不白屏；云端同步失败时降级本地存储；异常按 **用户操作 / 网络 / 服务端数据 / 环境限制** 分类，并给出对应友好提示。前端只做体验拦截，**权限与写配置最终以后端为准**。

装扮目录默认使用内置清单。App 启动通过 `bindThemeAdapters` 注入 `setThemeCatalogFetcher` / `setThemeCloudFlusher` / `setThemeMemberFetcher`；未注入时不会对目录接口发起请求。总览见 [`THEME_CENTER.md`](THEME_CENTER.md)。跳转链路见 [`THEME_CENTER_NAV.md`](THEME_CENTER_NAV.md)。运营后台见 [`THEME_CENTER_ADMIN.md`](THEME_CENTER_ADMIN.md)。

需求原文若另写一套超时句、失效过滤句、配额清理句，或要求「全部静默、无弹窗」，规划仍以本文 + ROADMAP 为准。**已落地 Toast / 对话框不得改**（e2e 与单测锁句）。不要另做增量异常协议、智能上报中台、一键修复向导。

对外文案不用「作品」「短视频」。Toast 仍不超过 32 字。

## 一期范围

| 做 | 不做（需求原文不采用） |
| --- | --- |
| 网络失败走缓存或 STATUS 空态 +【重试】；同步失败本地生效再排队 | 「网络请求超时，请稍后重试」等另一套超时句 |
| `style_json` 损坏跳过该层，回退默认 | 把坏样式写进真实页 |
| 搭配 / 最近使用里的下架件自动跳过 | 「部分装扮已失效，已为您自动过滤」——沿用「部分装扮已下架，已自动跳过」 |
| 启用 / 收藏 / 分享 / 保存搭配 / 重置 800ms 防抖；重复搭配前置拦截 | 无防抖连打 PUT |
| 配额满先清临时缓存，仍失败会话生效 | 「设备存储空间不足，部分缓存已清理」——沿用「存储空间不足，无法保存装扮配置，请清理存储空间」 |
| 小程序 SDK 低于 2.10.0 弹窗置灰；原生 nav/tab 不注入 | 为低版本浏览器另写一套 CSS 引擎 |
| 登录合并三选；登出清主题键 | 「异常全静默、无弹窗」——合并 / 覆盖确认 / 搭配上限仍要问 |
| 会员过期 Toast，停渲染不删配置 | 改成另一套权限过期弹窗 |
| 日志走已有 ANALYTICS / `theme_perf_error`，不上报账号 | 控制台抛技术栈；C 端异常流水页（三期）；投稿驳回另写 Toast（上线时再进本文，见 [`THEME_CENTER_UGC.md`](THEME_CENTER_UGC.md)）；兑换/复刻另写 Toast（见 [`THEME_CENTER_ECO.md`](THEME_CENTER_ECO.md)） |

H5 / 小程序拦截逻辑与提示句一致。局部异常不影响其它装扮。

## 异常分类

| 种类 | `THEME_FAULT_KIND` | 提示原则 |
| --- | --- | --- |
| 用户操作 | `user` | 防抖、存储上限、登录合并选择 |
| 网络 | `network` | 检查网络、重试；可展示缓存 |
| 服务端数据 | `data` | 资源异常、回退默认样式 |
| 环境限制 | `env` | 明确是小程序/版本限制，不是程序错误 |

Toast 文案见 `THEME_FAULT_TOAST`，长度不超过 32 字。

## 一、网络异常

1. **加载主题/装扮列表失败**  
   无缓存：空态「装扮列表加载失败，请检查网络后重试」+【重试】。  
   有缓存：继续展示列表，并提示「当前展示为缓存数据，部分内容可能不是最新」。

2. **保存装扮、同步云端失败**  
   先写入 H5 `localStorage` / 小程序 storage，当前页立即生效。  
   Toast：「装扮已本地生效，云端同步失败，稍后会自动重试」。  
   登录态下排队 `ui_theme_pack_cloud`，网络恢复（`onNetworkStatusChange`）后自动 flush。

3. **收藏、保存搭配失败**  
   本地已标记成功。Toast：「操作已本地保存，同步云端失败，网络恢复后自动同步」。

4. **接口超时**  
   装扮相关请求超时 **15 秒** 终止（`themeApi` 走 `httpClient` `timeout`）。超时当作网络失败：目录走缓存/空态，配置走本地 + 队列。页面保持可点。不要另发明超时 Toast。

5. **批量目录**  
   `GET /themes/` 与 `GET /decorations/` 其中一个失败时，用成功的一半更新内置清单，不因单侧失败拆整页。两侧都失败才走列表失败路径。

6. **网络恢复**  
   已登录则静默 flush 配置队列；已注入目录 fetcher 时再静默拉目录并 `mergeRemoteCatalog`。不弹「已恢复网络」。

未登录只写本地，不同步云端。

## 二、服务端数据异常

1. **装扮 id 不存在或已删除**  
   卡片置灰，标注「装扮已下架」；历史记录预览/启用置灰。一键应用跳过该装扮，Toast：「部分装扮已下架，已自动跳过」。最近使用缺 `id` / `item_type` 的坏行丢掉，不画空白卡；目录里已经没了的 id 仍展示置灰「已下架」。云端拉取失败时用本地 `ui_theme_recent`。

2. **缺少预览图或样式 JSON**  
   使用默认占位；提示「装扮资源加载异常」；启用按钮置灰。

3. **样式 JSON 损坏**  
   不渲染异常样式，回退系统默认。Toast：「装扮样式加载异常，已恢复默认」。

4. **目录字段缺失**  
   无 `theme_id` / `decoration_id` 的行丢掉，不进货架。名称等展示字段填空串或「装扮」，卡片仍画；不因缺简介 / 计数隐藏整卡。

5. **云端配置损坏**  
   `hydrateFromCloudConfig` 失败则保留本地，不覆盖成空皮。见 [`THEME_CENTER_SYNC.md`](THEME_CENTER_SYNC.md)。

## 三、权限与状态边界

1. **会员状态跨端未同步**  
   「会员状态正在同步，请稍候」，拉取完成后再渲染权限。会员从有效变为无效：Toast「会员已到期，会员装扮暂不可用」；已启用会员皮停止渲染，回退默认，**不删**配置。

2. **已拥有但小程序不支持该组件**  
   权限仍显示已拥有；标注「拥有权限，但小程序环境暂不支持该装扮」；启用置灰。一期 **藏** nav/tab 入口；二期置灰，见 ROADMAP。前置拦截，不打 apply、不注入原生栏 `style_json`。

3. **活动装扮已绝版**  
   卡片【已绝版】，无法再次启用（含曾经领取）；历史搭配一键应用自动跳过。

4. **创作者条件不再满足**  
   专属皮停止渲染，配置保留；达标并领取后可再生效。

5. **开启「全局主题覆盖局部装扮」且已有局部装扮**  
   弹窗：「开启全局主题覆盖局部装扮后，自定义局部装扮将不会生效，是否继续？」确认/取消。

6. **待上线**  
   仅可看详情 / 缩略；禁止启用、收藏新增、写入配置。见 STATUS / PREVIEW。

7. **越权**  
   前端置灰 + 引导；抓包改 id 由服务端 403/409，配置不变。提示走 SECURITY / PRIVILEGE，不要返回表名。

## 四、存储边界

1. **历史搭配满 10 套**  
   弹窗：「已达到最大保存数量，请删除旧搭配方案后再保存」。

2. **历史搭配组合重复**  
   Toast：「该搭配方案已保存，请勿重复添加」。收藏再次点击为取消，不是报错。

3. **一键应用全部失效**  
   Toast：「当前搭配无有效装扮，已恢复默认样式」。部分失效仍用「部分装扮已下架，已自动跳过」。

4. **搭配方案损坏**  
   Toast：「搭配方案异常，暂无法应用」。其它方案不受影响。

5. **本地存储空间不足**  
   先删除目录 / 检索等临时缓存，再重试写入核心配置。仍失败：Toast：「存储空间不足，无法保存装扮配置，请清理存储空间」。当前会话仍可临时生效，不持久化。

## 五、登录状态

1. **未登录**  
   只保存在本地。底部：「未登录状态，装扮仅保存在本地，登录后可同步到云端」。

2. **从未登录 → 登录**  
   云端配置优先。若本地有未同步装扮，询问：使用云端配置 / 使用本地配置 / 合并两者。

3. **账号 A 登出后登录 B**  
   清空旧账号本地装扮记录，加载新账号云端配置（由 `handleThemeAccountLogin` 在登录后执行）。

4. **登出 / token 失效**  
   立即清空本地主题相关键并回到默认皮，不把上一账号配置留给游客。罐头草稿仍按现网登出策略保留。

多端同时改配置：后一次成功的全量 PUT 为准，不弹冲突窗。离线操作进队列，联网有序 flush，见 SYNC。

## 六、小程序特有

1. **基础库过低**（低于 `2.10.0`）  
   弹窗：「当前小程序版本过低，请更新小程序后使用装扮功能」；相关按钮置灰。不支持的 API 不调用。异形屏 / 小屏走现有 PageShell 安全区，不为装扮另做一套布局引擎。

2. **保存分享海报被拒**  
   Toast：「保存海报失败，请授予相册权限」。

## 七、UI 交互

1. **连续点击启用/应用**  
   800ms 防抖，只执行一次。收藏、分享、保存/删除搭配、重置、预览打开同一套 `beginThemeApply`。短时间连切装扮合并为一次云端 PUT（300ms flush）。

2. **预览关闭时仍在渲染**  
   `abortThemePreview` 提升预览世代，终止预览渲染，不写入真实界面样式。

3. **空搜索词**  
   不进入搜索态，保留当前列表。剥标签后为空同样处理。

4. **搜索无命中**  
   「没有找到相关主题或装扮，换个关键词试试」。Toast：「没有匹配的主题装扮，请更换关键词」。

5. **筛选无命中**  
   Toast：「当前筛选条件下暂无可用装扮」。筛选面板【重置】恢复默认。

6. **写接口 429**  
   Toast：「操作过于频繁，请稍后再试」。不回滚本地已生效的免费皮，不暴露阈值。见 [`THEME_CENTER_SECURITY.md`](THEME_CENTER_SECURITY.md)。

## 八、提示规范

- 网络：检查网络、重试  
- 数据：资源异常、回退默认  
- 环境：小程序限制，不是 bug  
- 权限：开通会员 / 参与活动  
- 存储：清理空间  
- 限流：操作过于频繁，请稍后再试  

所有异常不得导致页面崩溃或白屏。不要把栈、SQL、签名算法展示给用户。溯源用 ANALYTICS 已有异常事件、`theme_fault`（同步失败 / 429 / 搭配满）与 PERF `theme_perf_error`（无 PII），不要 `console` 技术报错。

后台：非法 `style_json` 禁止入库；C 端脏数据只回退。运营报表与异常频次见 ADMIN / ANALYTICS（三期看板）。
